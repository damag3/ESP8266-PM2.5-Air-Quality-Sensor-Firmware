# ESP8266-PM2.5-Air-Quality-Sensor-Firmware
This firmware runs on an **ESP8266** and reads particulate matter (PM1.0 / PM2.5 / PM10) from a PMS5003‑type sensor using the Adafruit PM25 AQI library.   It exposes a **JSON API endpoint** used by the MagicMirror module **PM25Monitor**, and optionally displays values on an ST7735 TFT screen.
